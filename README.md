dokprod-infotrygdbrev
=====================

`dokprod-infotrygdbrev` er en app som kjører batchen `bdok100` - "behandle infotrygd brev" i nais. Batchen ble tidligere kjørt i `dokprod-batch`, som skal saneres.

For mer info kan du sjekke [dokumentasjonen for `bdok100` i confluence](https://confluence.adeo.no/spaces/BOA/pages/193992372/dokprodbatch+-+BDOK100)
